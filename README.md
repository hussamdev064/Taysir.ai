# تيسير.ai

> أداة عربية مجانية تحوّل وصف مشروعك إلى هوية بصرية أولية: شعار لفظي، لوحة ألوان، فكرة شعار، وأفكار مشاريع، مع نسخ النتائج وفتحها في Coolors وPinterest وطباعتها كملف PDF.

تيسير.ai تطبيق ويب ثابت، عربي بالكامل، يساعد الطلاب وأصحاب المشاريع على الحصول على بداية سريعة لهوية بصرية لمشروعهم، دون الحاجة إلى مصمم في البداية. يعمل التطبيق في المتصفح ويستخدم Google Gemini لتوليد المحتوى.

## المميزات

- واجهة عربية أصلية من اليمين إلى اليسار، متجاوبة مع الهاتف وسطح المكتب.
- إدخال وصف المشروع أو اختيار إحدى الأفكار المقترحة.
- أربع بطاقات للنتائج: الشعار اللفظي، لوحة الألوان، فكرة الشعار، وأفكار المشاريع.
- نسخ النتائج، فتح لوحة الألوان في Coolors، البحث عن مراجع شعارات في Pinterest، و printable عبر متصفح.
- وضع فاتح وداكن، مع احترام إعداد تقليل الحركة في النظام.
- إدخال مفتاح Gemini من نافذة في الرأس؛ يُحفظ المفتاح في ذاكرة الصفحة الحالية فقط ولا يُخزَّن.
- معالجة حالات الإدخال الفارغ، أخطاء API، واستجابات JSON غير الصالحة، وإزالة حالة التحميل دائماً.

## التشغيل محلياً

لا يحتاج المشروع إلى أدوات بناء أو مدير حزم.

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

ثم افتح:

```text
http://127.0.0.1:8000/index.html
```

## الاختبارات

```bash
python3 -m unittest discover -s tests -v
```

## الخصوصية

مفتاح Gemini الذي تُدخله عبر نافذة الرأس يبقى في ذاكرة الصفحة الحالية فقط، ولا يُكتب إلى ملفات التطبيق ولا يُرسل إلى أي جهة غير Google Gemini.
